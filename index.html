📚 How to Study — Qanday o'rganish kerak
🔁
Spaced Repetition
Intervalli takrorlash
Review new words after 1 day → 3 days → 7 days → 30 days. Fights the forgetting curve permanently.
Yangi so'zlarni 1 kun → 3 kun → 7 kun → 30 kun keyin takrorlang. "Unutish egri chizig'i"ga qarshi kurash.
🔬 Ebbinghaus 1885
🧠
Active Recall
Faol esga olish
Close the book and try to recall words from memory. The struggle strengthens memory more than re-reading.
Kitobni yoping va so'zlarni yoddan eslab ko'ring. Kurash o'zi xotirani mustahkamlaydi.
🔬 Roediger & Karpicke 2006
📓
Vocabulary Notebook
So'z daftari
Write each word by hand: English → pronunciation → Uzbek → example sentence. Review 5 min every morning.
Har so'zni qo'l bilan yozing: ingliz → talaffuz → o'zbek → misol gap. Har ertalab 5 daqiqa ko'rib chiqing.
🔬 Mueller & Oppenheimer 2014
🗣️
Read Aloud + Shadowing
Ovoz chiqarib o'qish
Read every sentence aloud. Then shadow native audio — repeat immediately after hearing. Fastest way to natural pronunciation.
Har gapni ovoz chiqarib o'qing. Native audioni eshitib, darhol takrorlang. Talaffuzni tezda o'rganish yo'li.
🔬 Krashen 1982
⏱️
Daily 55-Min Session
Kunlik 55 daqiqalik jadval
5m review yesterday → 20m new vocab + story → 15m write right + exercises → 10m tests → 5m write 3 sentences.
5d kecha so'zlar → 20d yangi so'z + story → 15d write right + mashq → 10d test → 5d 3 ta gap yoz.
🔬 Pomodoro + SRS
✏️
Write Wrong Words × 3
Xato so'zlarni × 3 yoz
Words you miss in Write Right — copy them 3 times, cover and write from memory. Do this before sleep every night.
Write Right'da noto'g'ri so'zlarni 3 marta ko'chiring, yoping va yoddan yozing. Har kech uxlashdan oldin bajaring.
🔬 Walker Sleep Lab 2017
